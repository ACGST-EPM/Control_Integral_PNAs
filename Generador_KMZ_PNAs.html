¿Qué hace esta herramienta? Captura de forma estandarizada los permisos (PNAs) y su historial de gestión, los ubica en el mapa (punto, línea o polígono) y descarga un .kmz listo para el análisis. Al elegir el tipo de permiso, la herramienta completa sola la autoridad, el plazo y los estados de trámite.
1Base de proyectos (la administra el gestor con clave)

Aquí se registran una sola vez los datos de identidad del proyecto. El Código Banco identifica cada proyecto (no se repite). Al crear un permiso se elige el proyecto de un menú y estos datos se copian solos (no se re-escriben). 🔒 La edición está protegida con clave de administrador. Guarda el JSON exportado como proyectos_db.json en el repositorio para conservarlo.
